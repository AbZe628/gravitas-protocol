# Scenario 07 — Gated token and one-transaction record

`GatedDemoSukuk` checks the registry in `_update` for its sole allowed manager route, mint and burn after construction. Direct and delegated ERC-20 transfers revert. The initial constructor mint is exempt because the token cannot be approved before its address exists. The holder must initiate a manager transfer; the manager checks asset and executor state, transfers in the same transaction and emits the policy version and hash. Tests check failed-route balances and allowances remain unchanged.

Run the reference tests and generate a fresh record from the deployed local contracts:

```bash
bash mb-sandbox-review/scripts/run-scenario-7.sh
```

The included [`reference-audit-record.json`](../reference-audit-record.json) is generated by `run-scenario-7.sh` from an actual local Anvil transaction. The verifier fetches and checks the transaction, receipt, block hash, expected chain ID, confirmation count, sender, calldata, ERC-20 `Transfer`, manager `TransferChecked`, same-transaction/block relationship, registry version and historical policy hash. It replays the ordered `PolicyUpdated` history and recomputes the hash chain. It also verifies serialized records against live RPC rather than trusting fields copied into JSON.

The full verification runs `reference/scripts/test-audit-verifier.py` immediately after Scenario 07 has generated a real record. The negative tests mutate that record (version, hash, amount, parties, event summaries, transaction identity, block hash and policy-history order/gaps) and use a local RPC proxy to remove or alter receipt logs and policy-history responses. Every mutation must be rejected; no fake transaction or fabricated audit evidence is used. The verifier also runs once with Python optimizations enabled to ensure checks do not depend on `assert` statements.

This local record proves only that this dummy code emitted those events on that local chain. It does not bind an investor identity, establish recipient eligibility, or establish legal or religious status. Registry policy version on the record is not a ruling or investor decision.
