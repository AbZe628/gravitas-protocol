# Reference implementation status

**Reference implementation, unaudited, for evaluation, not for production.**

This directory contains an illustrative gated demo token, a manager, a local JSON-RPC compliance API, and verification code. The token is called a demo sukuk only as a label. It is a dummy ERC-20 with no legal or religious standing. This is not an issuer product, Shariah opinion, regulator approval, independent audit, hosted service, or mainnet deployment.

The existing registry remains unchanged. The project imports it from `../../contracts` and uses the repository's existing OpenZeppelin v5.5.0 and nested Foundry test library. The source is supplied for evaluation only. Do not use it to issue or transfer a real instrument.
